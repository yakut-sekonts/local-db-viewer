# История версий

## 0.2.2

- Приложение переименовано в Local DB Viewer.
- Добавлены настройки SSL/TLS, CA certificates и SSLVerification для Trino.
- Добавлен встроенный Java runtime и прямой доступ к параметрам JDBC-драйверов через Advanced.
- Добавлены уведомления о новых версиях, проверка SHA256 и обновление по кнопке из приватных GitHub Releases.
- Пакеты выпускаются для macOS Apple Silicon ARM64 и Windows 11 x64 с установкой для текущего пользователя.
- В Advanced выбор «По умолчанию» возвращает значение из General/драйвера.
- Незавершённые транзакции, включая SQL с комментариями и savepoints, защищены от перезапуска при обновлении.

Первоначальная установка: скачайте DMG для macOS ARM64 или EXE для Windows x64. В IDE откройте колокольчик и один раз настройте личный GitHub-токен с доступом к этому приватному репозиторию. Последующие релизы появятся в приложении автоматически; кнопка обновления сохраняет SQL-консоли и перезапускает приложение.

Полная панель настроек по референсу ещё в работе: встроенный SSH tunnel, Schemas, расширенное управление сессиями и DDL mappings не входят в 0.2.2. macOS использует ad-hoc подпись без notarization, Windows — без Authenticode.


После обновления macOS может запросить доступ к Keychain из-за ad-hoc подписи. Для обновлений без повторного системного запроса нужен постоянный Developer ID.
