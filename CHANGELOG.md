# История версий

## 0.5.0

- Session templates: сохранённые шаблоны внутри подключения, отдельный выбор для SQL-консолей и интроспекции. Переопределяются authentication, read-only, Auto commit, startup script и JDBC driver version/class/JAR. Секреты шифруются, разные шаблоны используют отдельные физические соединения даже при Single session mode.
- В SQL-консоли можно выбрать шаблон, настройки подключения или шаблон по умолчанию; выбор сохраняется вместе с SQL-вкладкой. Изменения шаблона применяются после отключения сессии.
- DDL mappings связывает подключение и catalog/schema с локальным каталогом SQL-файлов. Trino/Presto, MySQL/MariaDB, ClickHouse и SQLite выгружают исходный DDL сервера. Перед записью показываются локальная и серверная версии; изменённые файлы выбираются явно, прежние версии сохраняются в .local-db-viewer-backup. Посторонние файлы не удаляются.
- Редактор DDL обнаруживает внешние изменения файла и предотвращает перезапись устаревшей версией. Добавлены ограничения размера, проверка UTF-8 и запрет файлов-ссылок.
- Консоли с DDL-подсказками читают CREATE TABLE и REFERENCES из локальных файлов, включая составные foreign keys. Подсказки колонок/JOIN и локальное дерево не обращаются к БД. Выполнение SQL по кнопке использует привязанное подключение.

DDL mapping — сравнение SQL-файлов и серверных определений, а не автоматический генератор ALTER-миграций. Для PostgreSQL, SQL Server и остальных JDBC-драйверов пока доступны готовые локальные SQL-файлы без серверной выгрузки. Локальный индекс не применяет ALTER и не выводит колонки из CREATE TABLE AS / views; такие ограничения показываются в замечаниях. SQL применяется к БД вручную из консоли, по одной выбранной команде.

## 0.4.0

- Добавлен SSH tunnel с password, private key/passphrase и SSH agent. Проверяется SHA256 fingerprint сервера; JDBC сохраняет исходное имя хоста для TLS. Поддерживаемые transports: Trino/Presto, PostgreSQL, MySQL, MariaDB, SQL Server и ClickHouse.
- Отдельные настройки truststore, CA-файла и клиентского сертификата/keystore. Возможности панели зависят от JDBC-драйвера; пароли SSH и сертификатов хранятся зашифрованными.
- Вкладка Schemas: выбранные схемы, include/exclude patterns, фильтры объектов в Explorer и автодополнении. Добавлены Auto sync, периодическая интроспекция и обновление дерева.
- Single session mode объединяет консоли и метаданные одного подключения. Очередь сериализует запросы; отмена ожидающего запроса не затрагивает выполняющийся. Keep-alive и auto-disconnect пропускают активные запросы и транзакции.
- Before connection: последовательный запуск программ с аргументами и timeout без shell; ошибка останавливает подключение.
- Windows updater заменён на отдельный EXE helper с уровнем asInvoker. Приложение остаётся открытым, пока helper не подтвердит готовность. NSIS устанавливает новую версию в каталог текущей копии; результат проверяется по версии EXE и подтверждению запуска новой IDE. Ошибки сохраняются и показываются после повторного открытия.

Если на старой версии Windows IDE закрывается и остаётся прежняя версия, один раз запустите установщик 0.4.0 вручную поверх существующей копии. Подключения и SQL-консоли сохраняются. Новый механизм обновления работает после этого перехода. Для публичного репозитория токен не нужен.

## 0.3.0

- Каталог расширен до 71 варианта подключения: SQL, аналитические системы и NoSQL через JDBC. 35 драйверов устанавливаются из Maven Central вместе с закреплёнными зависимостями; остальные подключаются импортом комплекта JAR производителя. Universal JDBC позволяет задать собственный Driver class и URL.
- Отдельное окно «JDBC-драйверы»: уведомления о новых версиях, установка по кнопке, сохранение прежних версий, возврат и закрепление версии в подключении. Открытые сессии сохраняют свой драйвер; обновление действует в новых сессиях.
- Каталог драйверов публикуется независимо от IDE в ветке driver-catalog. GitHub Actions проверяет версии каждые 6 часов; IDE проверяет каталог при запуске и каждый час. Для драйверов без публичного источника версий используется ручной импорт.
- Новые JDBC-подключения получают catalogs/schemas/tables/columns и foreign keys через DatabaseMetaData. Подсказки учитывают quoting, namespaces и регистр идентификаторов драйвера. Полнота метаданных зависит от драйвера и сервера; нативные NoSQL-консоли не добавлены.
- При `Cannot query Iceberg table` в Explorer показана причина и явный выбор другого доступного каталога. Смена connector требует подходящего каталога или настройки сервера Trino; приложение не подменяет объекты автоматически.
- Native TLS использует только явно заданный CA bundle и проверяет hostname во всех режимах проверки сертификата. JDBC-параметры FULL/CA/NONE по-прежнему передаются драйверу буквально.
- MySQL JDBC использует streaming ResultSet. LONGVARCHAR/LONGNVARCHAR читаются через ограниченный character stream с fallback только для неподдерживаемого JDBC-метода; VARCHAR Trino сохраняет совместимый getString.
- Ограничение размера строки ClickHouse применяется к байтам до readline. SQL lexer учитывает правила engine для backslash escapes, dollar quoting, identifiers и комментариев.
- Включён noUncheckedIndexedAccess. Добавлены проверки повреждённых профилей и ErrorBoundary: ошибка дерева не скрывает SQL-редактор и результаты.
- Проверены реальные H2 и DuckDB, две версии H2 с обновлением/откатом и сохранением открытых сессий, составной JOIN из автодополнения, Trino SSL/Unicode и обработка ошибки Iceberg.

Для пользователей версии 0.2.2–0.2.4 с ошибкой `fetch failed` нужна одна ручная установка нового EXE/DMG в прежнее место. Подключения и SQL сохраняются. С 0.2.5 обновление доступно через колокольчик; публичный репозиторий не требует токена.

## 0.2.5

- Обновления используют сетевой стек Electron с системным proxy/PAC и проверкой TLS-сертификатов. Устранена зависимость от Node fetch, из-за которой в корпоративных сетях возникало `fetch failed`.
- Публичные GitHub Releases доступны без токена. При отказе сохранённого токена загрузчик проверяет публичный доступ; поддержка приватных репозиториев сохранена.
- Исправлена обработка перенаправления GitHub API → CDN при скачивании установщика. Токен не отправляется на CDN; размер и SHA256 проверяются перед установкой.
- Ошибки proxy, DNS, TLS, таймаута, прав доступа и лимита GitHub показывают понятное сообщение и технический код.
- Добавлена проверка настоящего Electron-загрузчика через локальный HTTPS proxy на обеих платформах.

Если в 0.2.2–0.2.4 обновление завершается `fetch failed`, закройте IDE и один раз запустите новый Windows EXE либо замените macOS-приложение из DMG в прежнем каталоге пользователя. Подключения и SQL-консоли сохраняются. После перехода на 0.2.5 новые релизы проверяются внутри IDE; для публичного репозитория личный токен не требуется.

## 0.2.4

- Исправлено чтение текстовых колонок Trino: вместо ошибки `ResultSet.getCharacterStream is not yet implemented` результаты возвращают строки данных.
- Исправлена кодировка JDBC JSON-канала на Windows: кириллица и emoji передаются в UTF-8 без замены на `?`.
- Исправлена загрузка текстовых метаданных в Database Explorer: каталогов, схем и таблиц.
- Для обычных SQL character types используется `getString`; потоковое чтение сохранено для CLOB/NCLOB. Ограничение размера текстовой ячейки сохранено.
- Добавлен регрессионный тест с настоящим Trino JDBC: текст, CHAR, Unicode, NULL, пустые строки, bigint/decimal без округления, timestamp, binary и метаданные.

Настройки подключений и SSL менять не требуется. Обновление доступно через колокольчик → «Проверить обновления» → «Обновить и перезапустить».

## 0.2.3

- Кандидат с исправлением Trino: публикация остановлена после обнаружения потери Unicode в Windows-тесте.

## 0.2.2

- Приложение переименовано в Local DB Viewer.
- Добавлены настройки SSL/TLS, CA certificates и SSLVerification для Trino.
- Добавлен встроенный Java runtime и прямой доступ к параметрам JDBC-драйверов через Advanced.
- Добавлены уведомления о новых версиях, проверка SHA256 и обновление по кнопке из приватных GitHub Releases.
- Пакеты выпускаются для macOS Apple Silicon ARM64 и Windows 11 x64 с установкой для текущего пользователя.
- В Advanced выбор «По умолчанию» возвращает значение из General/драйвера.
- Незавершённые транзакции, включая SQL с комментариями и savepoints, защищены от перезапуска при обновлении.

Первоначальная установка: скачайте DMG для macOS ARM64 или EXE для Windows x64. В IDE откройте колокольчик и один раз настройте личный GitHub-токен с доступом к этому приватному репозиторию. Последующие релизы появятся в приложении автоматически; кнопка обновления сохраняет SQL-консоли и перезапускает приложение.

Полная панель настроек по референсу ещё в работе: встроенный SSH tunnel, Schemas, расширенное управление сессиями и DDL mappings не входят в 0.2.2. macOS использует ad-hoc подпись без notarization, Windows — без Authenticode.


После обновления macOS может запросить доступ к Keychain из-за ad-hoc подписи. Для обновлений без повторного системного запроса нужен постоянный Developer ID.
